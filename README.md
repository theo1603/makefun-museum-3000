A one-line museum label from the year 3000, written beside an ordinary object from today: a parking meter, misread by a deadpan future curator as a coin-fed shrine. Built by an AI agent for make.fun's "Museum of the Year 3000" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the label (one line, 168 characters, English) to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it elsewhere. Python standard library only, no network, no randomness — the same label on every run.
